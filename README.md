# VisualNovel Studio

將文字、角色立繪、背景與音樂組合成視覺小說，預覽完成後，匯出為 MP4 影片或可在瀏覽器播放的網頁。

你目前閱讀的是 `dev` 開發版指南。一般操作與正式版相同；以下新增功能仍在驗收，請使用專案副本測試。

## 開發版新增操作

- **製作續集**：「檔案 → 新增影片」。同一作品中的影片共用角色、素材與設定；有第二支影片後，左側會顯示影片切換列。
- **匯入既有角色**：在角色區選擇「從其他作品匯入…」，開啟另一份 `.vnsproj` 並勾選角色，程式會複製立繪；遇到同名角色會詢問如何處理。
- **導出範圍**：預覽與 MP4／ZIP／HTML 都只處理目前選取的影片。
- **存檔相容性**：舊專案儲存後會升級為 v2；不要覆蓋唯一的舊檔，也不要使用 main 回存開發版專案。

開發版尚有 UI 測試逾時與整套測試原生崩潰待調查，詳見 [驗證紀錄](docs/REPOSITORY_REVIEW.md)。

## 開始使用

### Windows 執行檔

如果你已取得打包版本，解壓縮完整資料夾，開啟其中的 **VisualNovel Studio.exe**。請保留旁邊的檔案與資料夾，不要只搬走 exe。

### 從原始碼啟動

需 Python 3.12 以上版本。在專案資料夾開啟 PowerShell，首次執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

下次只需執行最後一行，不必啟用虛擬環境或修改 PowerShell 執行原則。Linux / macOS 的啟動方式見 [開發指南](CONTRIBUTING.md)；這次整理未驗證這兩個平台。

## 製作第一個作品

### 1. 新增並儲存專案

選擇「檔案 → 新增專案」，再用「檔案 → 儲存專案」選擇存放位置。建議每個作品使用獨立資料夾。

專案檔副檔名是 `.vnsproj`，圖片與音樂另存於同一層的 `assets/`。備份或搬到另一台電腦時，請一起複製整個作品資料夾。

### 2. 匯入文字

選擇「檔案 → 匯入文字」，開啟 `.txt` 或 `.docx`；也可以用「檔案 → 貼上文字」直接貼入內容。

文字逐行處理：整行以 `「」` 包住的內容辨識為台詞，其餘為旁白；空行不會新增句子。例如：

```text
雨聲從窗外傳來。
「你終於來了。」
我放下手中的傘。
```

匯入後仍需自行指定說話角色。雙擊台詞可修改文字，右鍵選單可插入或刪除句子，也可以拖曳調整順序。

### 3. 加入背景、音樂與角色

在左側素材區匯入背景圖片與背景音樂，選擇場景後設定背景、BGM。再於角色列表新增角色，設定名字、名牌顏色與立繪；需要換裝或表情時，可編輯服裝與差分。

立繪建議使用透明背景 PNG，避免人物周圍出現色塊。

### 4. 指定說話者與舞台人物

台詞列的角色欄決定「誰在說話」；編輯區的左／中／右舞台軌道決定「誰出現在畫面」。兩者可分開設定，例如旁白時仍讓角色留在畫面。

在舞台軌道的空白處雙擊新增區段，設定角色、服裝與差分。拖曳區段上下邊緣可調整出場範圍。多選台詞後也能使用批次設置舞台。

### 5. 調整效果並預覽

使用特效軌道安排雨、雪或畫面震動等效果。預覽區可檢查人物、背景與文字，也能調整對話字級、名牌字級、文字顏色及對話框底色／透明度。

「外觀 → 主題」可更換編輯器主題。若預覽沒有更新，按 `F5` 重新整理。

### 6. 匯出與分享

從「導出」選單選擇格式：

| 格式 | 適合用途 | 如何使用 |
|---|---|---|
| MP4 影片 | 以影片方式分享或後製 | 用一般影片播放器開啟 |
| 網頁 ZIP | 分享完整網頁作品 | 先解壓縮，再開啟 `index.html`；分享時保留整包內容 |
| 單一 HTML | 用單一檔案傳送作品 | 用瀏覽器開啟；素材多時檔案會比較大 |

MP4 需要 FFmpeg。Windows 找不到 FFmpeg 時，程式會詢問是否下載；也可自行將 `ffmpeg.exe` 放在 `resources/ffmpeg/`，或將 FFmpeg 加入系統 `PATH`。

匯出前請先儲存專案；匯出的影片或網頁無法取代可繼續編輯的 `.vnsproj`。

## 常用操作

| 操作 | 快捷鍵／方式 |
|---|---|
| 新增／開啟／儲存專案 | `Ctrl+N`／`Ctrl+O`／`Ctrl+S` |
| 貼上文字 | `Ctrl+Shift+V` |
| 重新整理預覽 | `F5` |
| 修改句子 | 雙擊台詞 |
| 插入／刪除句子 | 在台詞列按右鍵 |
| 刪除選取句子 | 台詞列表中按 `Delete` |
| 複製選取句子文字 | 台詞列表中按 `Ctrl+C` |

## 常見問題

**開啟專案後圖片或音樂不見了？** 確認 `.vnsproj` 旁仍有完整的 `assets/` 資料夾。只搬動專案檔不會帶走素材。

**指定說話角色後看不到人物？** 檢查舞台軌道是否有涵蓋目前句子的角色區段，以及該角色是否已設定立繪。

**ZIP 網頁無法正常開啟？** 請先完整解壓縮，不要直接在壓縮檔內開啟 `index.html`。若瀏覽器限制本機載入，可改由本機網頁伺服器開啟。

**想使用多影片或跨作品匯入角色？** 這些功能在 `dev` 驗收。測試時請使用專案副本；開發版儲存的 v2 格式不能當作正式版可回讀的存檔。

**需要回報問題？** 從「說明」選單開啟日誌資料夾，附上重現步驟與相關錯誤。分享前請移除不想公開的作品文字、個人路徑與素材。
